# MarCADV1 Releases

Public binary release distribution for the modular MarCADV1 Revit suite.

The primary target is Revit 2024. The Installation Center will discover compatible stable releases and verify signed manifests and package integrity before installation. Installation starts after the user clicks Install or Update and requires Revit to be closed before replacement.

No validated client release is available yet. Local integration previews are not stable distributions. Plugin source and developer credentials are not hosted in this repository.
